How to use it
  1. Add states by double-clicking the canvas or with Add state.
  2. Create a transition by dragging from the edge of a state to another state (or to itself, for a loop).
  3. Click the transition and write its condition with ¬ (NOT), ∧ (AND) and ∨ (OR), e.g. (C ∨ D) ∧ ¬B. From the keyboard you can type !, & and | instead: (C | D) & !B. Transitions are evaluated whenever at least one input spikes.
  4. Click a state to mark it as active at start. Several states may be active at the same time.
  5. Check the generated network in Network and run it in Simulate.

Input spikes

The inputs are generated as a sequence of input events: time steps in which one or more inputs spike at the same time. The machine is only evaluated at these steps. A new random sequence is generated on every run.

Spacing between consecutive events, chosen at random in this range.

Type the spike times of each input in milliseconds, separated by commas.

Advanced parameters

Duration of one step t: synaptic delays and input spikes are multiples of it. The Ideal simulator accepts any value. SpiNNaker accepts any whole number of microseconds; below 1 ms it runs slower than real time.

Simulate the machine you have designed

Choose the simulator and how the input spikes are generated, then press Simulate. The network is built from spiking NOT/AND/OR gates and latches, simulated, and automatically compared with a reference automaton.
